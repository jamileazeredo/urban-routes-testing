# Urban Routes Testing

## Project Overview

This project contains the manual testing documentation for the Urban Routes web application, developed during the TripleTen QA Bootcamp.

The objective was to validate the application's functionality, identify defects, execute regression testing, and document the testing process using industry best practices.
