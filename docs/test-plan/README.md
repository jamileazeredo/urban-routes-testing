# Urban Routes – Regression Testing

## Project Overview

This project documents the regression testing performed on the Urban Routes web application, developed as part of the TripleTen Quality Assurance Bootcamp.

Urban Routes is a route planning application that calculates travel time and cost for different transportation methods. The goal of this project was to validate existing functionality, execute regression test cases, identify software defects, and create clear bug reports for the development team.

As my first Quality Assurance project, it provided hands-on experience with manual testing, test execution, and software defect documentation.

---

## Objectives

- Execute predefined regression test cases.
- Verify that existing functionality works as expected.
- Identify software defects.
- Document bugs using clear and structured reports.
- Practice software testing following QA best practices.

## Critical Analysis

This project introduced me to the practical workflow of a Quality Assurance Engineer.

Beyond executing test cases, I learned how important it is to compare expected and actual results carefully, write objective bug reports, and provide enough information for developers to reproduce defects.

One important lesson from the review was that bug titles should clearly describe **what happens, where it happens, and under which condition**. This feedback significantly improved the quality of my future bug reports.
